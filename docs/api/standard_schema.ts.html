standard_schema.ts

Standard Schema support, kept out of schema.ts so schemas don't carry a ~standard property they'd pay for in bytes and in a second object shape. Wrap a schema with to_standard_schema where a library asks for one.

@see https://standardschema.dev/

standard_schema.ts view source

StandardSchemaV1<TInput, TOutput> import type {StandardSchemaV1} from '@fuzdev/fuz_schema/standard_schema.js';

The Standard Schema types for a schema library without JSON Schema output, copied from version 1.1 of the spec as it recommends so there's no dependency on @standard-schema/spec. The spec nests its types in namespaces. Here each is flat, named by its path.

Left out: the spec's JSON Schema interface, which nothing here produces, and its inference helpers, which a consumer takes from the spec itself and which work on these types as they are.

to_standard_schema
#

standard_schema.ts view source

<T extends AnySchema>(schema: T): StandardSchemaV1<InferInput<T>, Infer<T>> import {to_standard_schema} from '@fuzdev/fuz_schema/standard_schema.js';

Wraps schema in a Standard Schema, for passing to libraries that accept one. The result is not itself a Schema, so it can't be nested in other schemas.

Its validate is synchronous and ignores the options argument, and types is left unset: the input and output types are carried by the return type.
