fuz_schema

a performance-focused
schema library for JS

fuz_schema takes Valibot's approach, with a tree-shakeable function per schema, schemas as plain objects, pipe for refinement, and pushes it further on bundle size, speed, and memory, with simpler internals. It's published as @fuzdev/fuz_schema and is pre-1.0; feedback is welcome in the issues and discussions.

For now this site has only benchmarks and the generated API reference docs. For usage docs, see the README.
